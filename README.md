# Phong Thủy App 🏠✨

Ứng dụng Phong Thủy đơn giản, dễ dùng trên điện thoại.

## Tính năng
- Tính **Cung mệnh** (Bát Trạch) theo năm sinh
- Xem **hướng tốt / hướng xấu** (Sinh Khí, Thiên Y, Diên Niên, Phục Vị, Tuyệt Mệnh...)
- Xem **Ngũ hành bản mệnh**
- Gợi ý hướng nhà, hướng giường, bàn làm việc phù hợp
- Giao diện đẹp, hỗ trợ cài đặt như app (PWA)

## Cách sử dụng
1. Mở link: https://nguyenxuandat20091985-rgb.github.io/phong-thuy-app/
2. Trên điện thoại: nhấn **Thêm vào Màn hình chính** / **Add to Home Screen** để cài như app.

## Công nghệ
- HTML + CSS + JavaScript thuần
- Progressive Web App (PWA)
